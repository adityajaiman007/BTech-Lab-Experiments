# ShopSphere - Online Shopping System

## Project Description
ShopSphere is a Java-based online shopping application.

## Features
- Display available products
- Select products
- Add products to cart
- Calculate total price
- Display order summary

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming

## How to Run
Compile and run the Java source file using the Java Development Kit (JDK).

## Result
A basic online shopping system developed using Java.
