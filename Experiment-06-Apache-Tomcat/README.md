# Experiment 6 - Introduction to Apache Tomcat

## Aim
To study Apache Tomcat and understand its role in running Java web applications.

## Theory
Apache Tomcat is an open-source web server and servlet container used to run Java Servlets and JavaServer Pages (JSP).

## Features
- Supports Java Servlets
- Supports JSP
- Handles HTTP requests and responses
- Deploys Java web applications

## Result
To understand the basics of Apache Tomcat and its use in Java web development.
