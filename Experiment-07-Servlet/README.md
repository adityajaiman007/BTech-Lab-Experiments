# Experiment 7: Servlet

## Aim
To study Java Servlets and understand how they handle HTTP requests and responses.

## Theory
A Servlet is a Java program that runs on a web server such as Apache Tomcat. It processes client requests and generates responses.

## Software Required
- Java JDK
- Apache Tomcat
- IDE or text editor

## Result
Studied the basic concept and working of Java Servlets.
